# Documents

| File | Purpose | Enable in |
|---|---|---|
| `sponsorship-deck.pdf` | Partnership deck (< 10 MB) | `src/data/site.ts` → `documents.sponsorshipDeck.available = true` |
| `technical-summary.pdf` | Aircraft technical summary (< 5 MB) | `documents.technicalSummary.available = true` |
| `press/` | `logo-pack.zip`, `fact-sheet.pdf`, `photos.zip` | `documents.pressKit.available = true` |

Download buttons only appear once the corresponding flag is set to `true`.
