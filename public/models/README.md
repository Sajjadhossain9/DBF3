# 3D models

Expected file: `airborne-phoenix-aircraft.glb`

- Format: glTF binary (.glb), Y-up, metres, nose pointing +Z, centred at origin.
- Budget: < 3 MB, < 150 k triangles, textures ≤ 2048 px (KTX2/Draco optional but the loader currently expects uncompressed glTF).
- Export from SolidWorks/Fusion via OBJ/STEP → Blender → glTF (apply decimation, merge small fasteners).

Until this file exists the viewer displays a clearly-labelled **temporary demonstration model** that does not represent the team's design.
