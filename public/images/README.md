# Images

| Folder | Content | Recommended size | Format / max size |
|---|---|---|---|
| `hero/` | Hero stills; `hero-poster.webp` (video poster, 1920×1080, 16:9) | 1920×1080 | WebP/AVIF, < 250 KB |
| `aircraft/` | Aircraft studio shots, side/top/front, details | 2000×1333 (3:2) | WebP/AVIF, < 400 KB |
| `team/` | Portraits `<slug>.webp`, consistent lighting, neutral background | 800×1000 (4:5) | WebP, < 200 KB |
| `engineering/` | CAD renders, CFD/FEA plots, workshop photos, video posters | 1600×1000 (16:10) | WebP/PNG for plots, < 400 KB |
| `gallery/` | Archive photos (register in `src/data/gallery.ts` with `w`/`h` aspect) | 1600 px long edge | WebP/AVIF, < 350 KB |
| `news/` | Article cover images | 1600×900 (16:9) | WebP, < 300 KB |
| `sponsors/` | Logos `<sponsor-id>.svg` (preferred) or transparent PNG ≥ 600 px wide | — | SVG / PNG, < 100 KB |

Also place `icon-192.png` and `icon-512.png` (PWA icons, square, safe-zone 80 %) directly in this folder.
